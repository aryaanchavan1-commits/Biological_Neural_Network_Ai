Biologically Inspired Neural Network Research Framework

BIO-NN is a modular research framework for experimenting with biologically-inspired neural network mechanisms. It tests whether synaptic plasticity, structural adaptation, sparse coding, and neuromodulation can improve continual learning, robustness, and computational efficiency.
