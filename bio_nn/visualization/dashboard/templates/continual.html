Continual learning tests whether the network can learn new tasks without forgetting old ones. In class-incremental learning, tasks are presented sequentially (e.g., first learn digits 0-1, then 2-3, etc.). Catastrophic forgetting occurs when learning new tasks causes the network to forget previous ones. BIO-NN uses structural plasticity and homeostatic mechanisms to mitigate this.
